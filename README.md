# teamcook

**AI 팀을 레시피로 요리하세요.**

멀티 에이전트(Codex·Claude Code 등)를 쓰는 사람이 **AI 팀을 부리는 고용주**가 되게 하는 도구입니다.
실행은 Claude Code·Codex에서, **팀을 보고 · 고치고 · 보고받는 것**은 여기서 합니다.

사이트: https://teamcook-eta.vercel.app/

## 문이 두 개 있습니다

| | 웹 (사이트) | 작업실 (내 컴퓨터) |
|---|---|---|
| 누구에게 | 처음 해 보는 사람, 무료 계정만 있는 사람 | 이미 Claude Code·Codex로 팀을 돌리는 사람 |
| 첫 질문 | "어떤 일을 AI 팀에게 맡길까요?" | "어느 프로젝트를 볼까요?" |
| 하는 일 | 내 AI 요금제에 맞는 **레시피 추천**, 레시피 책, 설치용 파일 내보내기 | 프로젝트의 **팀원 보기·고치기**, **업무 일지** |
| 말투 | 요리 (레시피·재료) | 회사 (팀원·업무 일지) |
| 여는 법 | 주소만 열면 됨 | 터미널에서 `npx teamcook open` (아래 참고) |

코드는 하나이고, 화면이 알아서 어느 문인지 골라 보여 줍니다.

## 웹에서 할 수 있는 것

- **레시피 추천:** "블로그 글을 쓰고 싶다"처럼 적으면, 내 AI 요금제와 사용량 여유에 맞는 레시피를 골라 이유와 함께 보여 줍니다. AI를 호출하지 않고 낱말과 내 플랜으로 계산합니다.
- **레시피 책:** 검증된 팀 구성 21종을 상황별로 모아 두었습니다. 직접 만들거나 불러올 수도 있습니다.
- **팀 설계:** 작성자·검토자·조사원 같은 역할 카드와 넘겨주기 흐름으로 팀을 짭니다.
- **실행 경로 확인:** 카드마다 내 플랜으로 쓸 수 있는 가장 좋은 경로(① 구독 ② API 키 ③ 무료 한도 ④ 복사·붙여넣기)를 보여 주고, 막힌 곳에는 🔒와 대안을 알려 줍니다.
- **필요한 플랜 배지:** "ChatGPT 무료로 가능", "Claude Pro 필요" 같은 배지가 레시피마다 자동으로 붙습니다.
- **조리법(협업 방식):** 서브에이전트, Claude Code 에이전트 팀(실험 기능), 프롬프트만 쓰는 토론형 중에서 고릅니다.
- **사용량 어림:** 가벼움·보통·무거움으로 보여 주고, 내 여건에서 어디서 나가는지 알려 줍니다. 토큰이나 금액은 짐작해서 적지 않습니다.
- **내 AI:** ChatGPT·Claude·Gemini·Grok 요금제와 API 키 보유 여부(키 값은 받지 않음)를 골라 두면 추천에 반영됩니다. 요금제마다 구독에 포함된 API 크레딧도 보여 줍니다.
- **공유:** 서버 없이 링크 하나에 레시피를 담아 나눕니다.
- **내보내기·불러오기:** `.codex/agents/*.toml`, `.claude/agents/*.md`, `recipe.json`, 설명서(`RECIPE.md`)를 zip으로 내보냅니다. 내보내기 전에 빠진 곳을 점검해 줍니다.
- **도움말·재료 사전:** 멀티 에이전트가 처음인 사람을 위해 재료(에이전트)·조리법·주방(실행 도구)·재료비(토큰) 비유로 설명합니다.

로그인도, 서버 저장도, API 키 입력도 없습니다. 모든 데이터는 내 브라우저에만 저장됩니다.

## 작업실: 내 팀을 보고 · 고치고 · 보고받기

내 프로젝트의 숨김 폴더(`.claude/agents`, `.codex/agents`) 속 역할 파일을 읽어 줍니다.

- **팀원:** 역할 파일을 팀원 카드로 보여 줍니다. 맡길 일·권한을 고치면 그 파일에 바로 저장합니다. 레시피로 팀원을 들일 수도 있습니다.
- **활동:** 이 폴더에서 AI가 한 일(대화·내가 한 말·고친 파일·팀원별 일한 양)을 대화 기록에서 모아 보여 줍니다. 읽기 전용으로 적힌 팀원이 파일을 고쳤는지도 점검합니다. 팀원을 쓰지 않는 폴더에서도 볼 것이 생깁니다.
- **업무 일지:** Claude Code·Codex가 남긴 대화 기록에서 누구에게 무엇을 시켰고 무엇을 돌려받았는지(누가 누구에게 다시 맡겼는지까지) 보여 줍니다. 기록은 **읽기만** 합니다.
- **실시간:** 역할 파일이 바뀌거나 기록이 새로 쌓이면 화면이 저절로 따라옵니다.

### 써 보기

```bash
npx teamcook open      # 브라우저가 열립니다. 끝낼 때는 Ctrl+C
```

Node.js 20 이상이 필요하고, 22.15 이상을 권합니다(Codex의 압축된 `.zst` 기록은 Node에 들어 있는 압축 풀기를 씁니다).
처음 화면에 최근에 AI를 쓴 프로젝트가 자동으로 나옵니다. 옵션은 `--port <번호>`(기본 4417), `--no-browser`입니다.

이 저장소를 받아 고치면서 쓸 때는 `npm install`, `npm run build`(화면 파일 `dist/`를 먼저 만든다), `npm run open` 순서입니다.

### 무엇을 읽고, 무엇을 쓰나요

작업실 도우미는 **사용자가 직접 `teamcook open`(또는 `npm run open`)을 했을 때만** 동작하고, 화면에 읽는 곳을 늘 적어 둡니다.

- 읽는 곳: `~/.claude/projects`와 `~/.codex/sessions`의 대화 기록 파일(`.jsonl`, `.jsonl.zst`), 그리고 고른 프로젝트의 `.claude/agents`, `.codex/agents`, `.teamcook/`
- 쓰는 곳: 고른 프로젝트의 역할 파일과 `.teamcook/` 뿐입니다. 설정 파일(`.codex/config.toml`, `.claude/settings.json`)은 고치지 않고, 없을 때 새로 만들기만 합니다.
- 열지 않는 것: 인증·설정 파일(`auth.json`, `.credentials.json`, `.env` 등)은 목록에도 나오지 않습니다.
- 안전장치: `127.0.0.1`(이 컴퓨터)에서만 열리고, 실행할 때마다 새로 만드는 일회용 열쇠가 있어야 합니다. AI를 실행하지 않고, 아무것도 바깥으로 보내지 않습니다.

실제 내 폴더와 T3 Code로 돌린 기록이 일지에 잡히는지는 아직 확인 중입니다. 가짜 폴더로는 자동 검사를 마쳤습니다.

## 레시피를 프로젝트에 바로 설치

```bash
cd 내-프로젝트
node -e "fetch('https://raw.githubusercontent.com/fun5307/teamcook/main/cli/teamcook.mjs').then(r=>r.text()).then(t=>require('fs').writeFileSync('teamcook.mjs',t))"
node teamcook.mjs add "<공유 링크>"
```

첫 줄은 설치 도구 파일 하나를 내려받고, 둘째 줄이 레시피를 설치합니다 (Node.js 20 이상).
이미 있는 파일은 건드리지 않습니다(`--force`로 덮어쓰기, `--dry-run`으로 미리 보기).

## 하지 않는 것

- 에이전트를 직접 실행하거나 세션·스레드를 관리하지 않습니다. T3 Code, 1Code 같은 실행 도구와 경쟁하지 않고, 대화 기록은 읽기만 합니다.
- 서비스 안에서 API 키로 에이전트를 돌리지 않습니다. API 키 값은 받지도 저장하지도 않습니다.
- 회원가입, 로그인, 서버 DB가 없습니다. 공유는 링크만으로 합니다.
- 무료 웹 채팅 계정을 자동으로 로그인하거나 화면을 긁지 않습니다(약관 위반).

## 개발

```bash
npm install
npm run dev          # 개발 서버 http://localhost:5173
npm test             # 단위 테스트 (Vitest, 374개)
npm run typecheck    # 타입 검사
npm run build        # 배포용 빌드 (dist/)
npm run build:cli    # 설치 명령·작업실 도우미 묶음 (cli/teamcook.mjs)
npm run open         # 작업실 도우미 (먼저 npm run build)
```

Node.js 20 이상이 필요합니다. 기술 구성은 React 19, TypeScript, Vite, Tailwind, shadcn/ui, zustand입니다.

> Windows에서는 `npm test`가 `scripts/vitest.mjs`를 거쳐 실행됩니다. 터미널의 드라이브 문자가 소문자(`c:\...`)일 때 생기는 문제를 피하기 위해서이니, `npx vitest`를 직접 실행하지 마세요.

`src/cli/`나 변환기(`src/converters/`)를 고치면 `npm run build:cli`로 `cli/teamcook.mjs`를 다시 만들어 함께 커밋해야 합니다. 설치 명령이 이 파일을 GitHub에서 직접 받아 쓰기 때문입니다.

## 문서

- `CLAUDE.md` / `AGENTS.md`: 작업 규칙과 폴더 구조 (AI 코딩 도구용, 두 파일은 같은 내용)
- `HANDOFF.md`: 현재 상태, 결정과 그 이유, 다음 할 일
- `지시서들/`: 전체 지시서(`PROJECT_BRIEF.md`), 전략 문서(`MCP-strategy.md`), 단계별 지시서
- `design/`: 디자인 시안과 화면 기록

요금제·설정 형식은 빠르게 바뀝니다. 결제 전에는 각 회사의 공식 페이지를 확인하세요. 화면의 "요금 안내" 링크가 공식 페이지로 연결됩니다.
